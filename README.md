# 🧮 Math Magician

Math Magician is a responsive calculator website built with **HTML, CSS, and JavaScript**. It combines a simple calculator with an informative home section and an inspirational mathematics quote.

The project provides an interactive way to perform basic arithmetic operations while practicing front-end web development.

## ✨ Features

* **Home Section:** Introduces calculators and explains their basic functions.
* **Interactive Calculator:** Performs addition, subtraction, multiplication, and division.
* **Percentage Calculation:** Converts a number into its percentage value.
* **Positive/Negative Toggle:** Changes the sign of a number.
* **Decimal Support:** Allows calculations involving decimal numbers.
* **Clear Function:** Resets the calculator using the AC button.
* **Error Handling:** Displays an error when attempting to divide by zero.
* **Navigation Bar:** Provides links to the Home, Calculator, and Quote sections.
* **Inspirational Quote:** Displays a quote about mathematics.
* **Responsive Design:** Adjusts the layout for desktop, tablet, and mobile screens.
* **Background Image:** Uses a calculator-themed background image.

## 🛠️ Technologies Used

* **HTML5** — Structures the website and its content.
* **CSS3** — Styles the website, calculator, navigation bar, and responsive layouts.
* **JavaScript** — Implements calculator functionality and button interactions.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all project files, including `calculator.jpg`, are in the correct locations.
4. Open `index.html` in your browser.

**Recommended:** Install the Live Server extension in Visual Studio Code and select **Open with Live Server** to run the website locally.

## 🧮 Calculator Operations

| Operation      | Symbol | Description                                  |
| -------------- | ------ | -------------------------------------------- |
| Addition       | +      | Adds two numbers                             |
| Subtraction    | −      | Subtracts the second number from the first   |
| Multiplication | ×      | Multiplies two numbers                       |
| Division       | ÷      | Divides the first number by the second       |
| Percentage     | %      | Divides the selected number by 100           |
| Sign Change    | +/-    | Changes a number's positive or negative sign |
| Clear          | AC     | Resets the calculator                        |
| Decimal        | .      | Supports decimal numbers                     |
| Calculate      | =      | Displays the calculation result              |

## 📱 Responsive Design

The website includes CSS media queries to adjust its layout for different screen sizes.

* **Desktop:** Displays the navigation bar, content sections, and calculator in a desktop-oriented layout.
* **Tablet:** Adjusts spacing and calculator positioning.
* **Mobile:** Uses a vertically arranged navigation bar and a more compact calculator layout.
